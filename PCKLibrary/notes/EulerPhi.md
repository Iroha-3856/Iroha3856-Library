# Euler の φ 関数と約数包除

## 定義と計算式

`φ(n)` は `1 <= x <= n` かつ `gcd(x, n) = 1` を満たす整数 `x` の個数。
`n` の異なる素因数を `p` とすると、素因数ごとの倍数を包除して次を得る。

```text
φ(n) = n Π (1 - 1/p)
     = n Π (p - 1) / p
```

したがって、`n` を素因数分解し、異なる素因数 `p` ごとに `ret -= ret / p` とすればよい。
計算途中では常に割り切れる順番なので、浮動小数点数は使わない。

`1..N` の全ての φ を求める場合は、`phi[i] = i` で初期化し、素数 `p` の倍数全てに
`phi[x] -= phi[x] / p` を適用する。これは φ の篩で、計算量は `O(N log log N)`。

## gcd ごとの分類

`1 <= x <= n` を `gcd(x, n)` の値 `d` ごとに分類する。
`gcd(x, n) = d` なら `x = dy` と書け、`gcd(y, n/d) = 1` なので、その個数は `φ(n/d)`。
全ての `x` がちょうど一つの分類に入ることから、次の恒等式を得る。

```text
Σ φ(d) = n
d|n
```

よく使う言い換えは次のとおり。

- `gcd(x, n) = d` となる `1 <= x <= n` の個数は `φ(n/d)`。
- `gcd(x, n)` のみに依存する和は、約数 `d` ごとの和へ変換できる。
- 分母がちょうど `n` の既約分数の個数は `φ(n)`。
- 長さ `n` の周期構造を「最小周期」や「回転対称性」で分類すると φ が現れやすい。

## 区間内で互いに素な数を数える

`n` の異なる素因数を `p_1, ..., p_k` とする。
`1 <= x <= M` で `n` と互いに素な `x` は、どの `p_i` の倍数でもない数なので包除原理で数えられる。

```text
Σ (-1)^|S| floor(M / Π p)
S⊆{1,...,k}         i∈S i
```

異なる素因数の個数が小さいときは、部分集合を直接列挙すれば `O(2^k)`。
同じ式を Möbius 関数で書くと次になる。

```text
#{1 <= x <= M | gcd(x, n) = 1}
    = Σ μ(d) floor(M/d)
      d|n
```

`μ(d) = 0` となる平方因子を持つ約数は寄与しないため、実際には `n` の異なる素因数の積だけを列挙すればよい。

さらに `d | n` として、`gcd(x, n) = d` を満たす `1 <= x <= M` の個数は、`x = dy` として
次の形に落とせる。

```text
Σ μ(e) floor(M/(de))
e|(n/d)
```

## 約数包除と Möbius 反転

約数について

```text
F(n) = Σ f(d)
       d|n
```

という関係があるとき、Möbius 反転により

```text
f(n) = Σ μ(d) F(n/d)
       d|n
```

と戻せる。`Σ_{d|n} φ(d) = n` も約数和の関係であり、φ は恒等関数 `f(n)=n` の
Möbius反転として

```text
φ(n) = Σ μ(d) n/d
       d|n
```

と表せる。

問題で「値が `n` を割る」「gcd が同じものをまとめる」「全約数への寄与を足す」が現れたら、
`gcd` ごとの分類、約数包除、Möbius反転のいずれかを疑う。
